# Team conventions
- Keep this project as one Spring MVC + Thymeleaf application, matching the PE reference.
- Use controller -> service -> service/impl -> repository -> entity. DTOs stay in dto/.
- Java 21, Spring Boot 4.1.1, PostgreSQL 16. No React runtime in this base.
- Treat docs/reference/erd_car.drawio as the original snapshot. Changes go in a separate proposed ERD.
- Conceptual ERD has 13 entities; physical ERD and embedded Mermaid metadata are older.
- SLOT means a rental time window for a vehicle type, as clarified by the user.
- Shared entity/schema changes require coordination with Kiet before implementation.
- Database schema is database-first; never switch ddl-auto to create/create-drop.
- Do not commit real credentials, uploads, IDE folders, or target/.
- Never push to GitHub until the user confirms the destination and visibility.
