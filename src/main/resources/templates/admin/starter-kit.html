Bảng chuẩn màu Status Badges

Sử dụng ~{fragments/admin-components :: statusBadge(...)} để không bao giờ bị lệch màu:

Bộ nút bấm chuẩn (Buttons)

Ví dụ Copy-Paste mẫu cho Thành viên trong nhóm

Để gọi component trong bất kỳ file Thymeleaf nào, chỉ cần chèn 1 dòng: 

<!-- 1. Tiêu đề trang chuẩn -->
<div th:replace="~{fragments/admin-components :: pageHeader(title='Quản lý khuyến mãi', subtitle='Tạo và điều chỉnh mã giảm giá', backUrl='/admin/dashboard')}"></div>

<!-- 2. Thẻ thống kê KPI -->
<div th:replace="~{fragments/admin-components :: statCard(label='TỔNG SỐ XE', value='45', subtext='Đang vận hành', iconType='car', variant='primary')}"></div>

<!-- 3. Badge trạng thái tự động -->
<div th:replace="~{fragments/admin-components :: statusBadge(status='active', label='Đang thuê', variant='success')}"></div>

<!-- 4. Thông báo Flash alert -->
<div th:replace="~{fragments/admin-components :: alert(type='success', message=${success})}"></div>

Hộp thoại Xác nhận (Modal Component)

Đây là mẫu Modal chuẩn giao diện SaaS. Các chức năng như Bàn giao xe (Phú), Tạo mã voucher (Trí), hay Báo cáo sự cố (Phúc) có thể dùng trực tiếp cấu trúc HTML này mà không bị lỗi giao diện.
